# HADK v2.1 Agent-Compatible Handoff

HADK supports Claude Code, Codex, and OpenCode as packet consumers. It does
not execute agents or run a multi-agent runtime.

```bash
hadk architecture plan
hadk handoff implement --agent claude-code
hadk handoff import .hackathon/artifacts/generated/handoff/result.yaml
```

The exported context pack includes reviewed facts, selected idea, locked scope,
architecture, acceptance criteria, verification commands, out-of-scope rules,
and security rules. Each task packet contains allowed and forbidden files,
scope/architecture versions, dependencies, fallback behavior, and an expected
result schema.

Imported results are `agent_reported`, not `verified`. Stale versions and
unauthorized file claims are rejected.
