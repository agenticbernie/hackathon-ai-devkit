# HADK v2.1 Verification

`hadk verify build` runs the project contract from `prototype/` using argument
arrays and a confined working directory:

1. install dependencies;
2. typecheck;
3. test;
4. production build;
5. start;
6. healthcheck.

Each step captures redacted stdout/stderr as checksummed evidence. A failure
blocks the build gate. An empty `node_modules` directory, a plan, or a prompt
export is not evidence.

`hadk verify demo` runs reset/seed, startup, healthcheck, and the configured
demo journey. If automation is unavailable, use:

```bash
hadk verify demo --human \
  --operator "Name" \
  --checklist "reset complete;core flow observed;fallback observed" \
  --media screenshots/demo.png
```

Human attestation is explicitly labeled non-automated. Video rendering is
optional and outside the core gate.
