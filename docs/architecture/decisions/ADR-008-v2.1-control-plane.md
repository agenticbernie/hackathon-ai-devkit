# ADR-008: v2.1 Evidence-Backed Competition Control Plane

## Status

Accepted.

## Context

The v2.0 pipeline produced useful artifacts but several gates inferred success
from structure, heuristics, or intended actions. That creates an unsafe
difference between a plan and a verified delivery result.

## Decision

HADK v2.1 is repositioned as a competition delivery control plane. The
canonical state and evidence contracts are shared by all packages. A phase can
advance only when its validator has a matching evidence record or explicit
human attestation. Agent integrations export and import typed packets but do
not execute agents.

The old scaffold and HyperFrames integrations remain compatible, deprecated
and outside the v2.1 core path.

## Consequences

- More explicit user review is required for facts and idea selection.
- Real project commands run during build verification.
- Demo and submission claims are inspectable and reproducible.
- Existing state and commands migrate without deleting artifacts.
- The control plane does not pretend to be an autonomous build system.
