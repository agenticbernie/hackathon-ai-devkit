# HADK v2.1 Boundaries and Threat Model

## Trust boundaries

1. Competition URLs and local briefs are untrusted external data.
2. Imported YAML/JSON, agent prompts, agent results, and generated content are
   untrusted data.
3. Shell commands execute only from an allowlisted verification contract in a
   confined project root.
4. `.env*`, credentials, private keys, cloud credentials, raw private briefs,
   and agent logs are protected from ingestion and evidence persistence.

## Non-goals

The core path does not execute agents, generate universal applications,
render video, perform startup research, or submit to an external competition.

## Safety invariants

- A path must resolve under the project root unless explicit opt-in is given.
- Symlink escapes are rejected.
- URL fetches reject private, loopback, link-local, and metadata addresses,
  validate redirects, enforce response limits and timeouts, and check content type.
- Commands use `execFile` with an argument array, never shell interpolation.
- Verification failures block gates.
- A prompt export is never an execution result.
