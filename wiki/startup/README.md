# Startup Wiki

Use this workflow when the goal is venture validation, not only a compelling demo.
Startup discovery is problem-first and does not require `selected-idea`.

## Workflow

```text
source/file/URL
  -> pain-point research
  -> opportunity scorecard
  -> pain-point deep dive
  -> validation plan
  -> customer evidence
  -> startup status / next
```

Start with [problem discovery](discovery.md), then use [venture analysis](venture-analysis.md)
for the broader startup-contest workflow.
